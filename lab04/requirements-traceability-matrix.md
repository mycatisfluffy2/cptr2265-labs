# Requirements Traceability Matrix

| Requirement ID | Functional Requirement | User Story |
|---|---|---|
| 1 | The system shall allow the user to perform calculations using addition (+), subtraction (-), multiplication (*), and division (/). | Story 1 – Perform Calculations |
| 2 | The system shall allow the user to use parentheses to group mathematical expressions. | Story 1 – Perform Calculations |
| 3 | The system shall allow the user to perform exponent calculations using the caret operator (^), such as `3^6`. | Story 1 – Perform Calculations |
| 4 | The system shall evaluate mathematical expressions according to standard mathematical order of operations. | Story 1 – Perform Calculations |
| 5 | The system shall allow the user to enter calculator expressions using the computer keyboard. | Story 2 – Enter Calculations and View Results |
| 6 | The system shall provide graphical calculator controls that allow the user to enter numbers and mathematical operators without requiring keyboard input. | Story 2 – Enter Calculations and View Results |
| 7 | The system shall display the result of the valid calculation to the user. | Story 2 – Enter Calculations and View Results |
| 8 | The system shall identify calculator expressions that contain invalid or unsupported input. | Story 2 – Enter Calculations and View Results |
| 9 | The system shall provide an indication to the user when a calculation contains invalid input rather than silently failing. | Story 2 – Enter Calculations and View Results |
| 10 | The system shall record calculations performed during the current calculating session. | Story 3 – View Calculation History |
| 11 | The system shall display the user's calculation history for later reference. | Story 3 – View Calculation History |
| 12 | The system shall provide a text area where the user can write and organize notes related to their calculations. | Story 4 – Use Notes and View the Application Layout |
| 13 | The system shall display the calculator, calculation history, and notes as the three primary sections of the application. | Story 4 – Use Notes and View the Application Layout |
